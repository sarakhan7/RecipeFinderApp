# Recipe Finder App

> A simple and easy-to-use recipe search tool powered by TheMealDB. Enter ingredients, get recipes, and cook! 

![App Screenshot](https://github.com/user-attachments/assets/4c05fd25-f699-4d61-ab29-f315d45e871f)


---

## Features 

- Search recipes by ingredients  
- Displays images, ingredients, and recipe links  
- Clean, responsive, and kawaii-themed UI  
- Instant results from TheMealDB API  
- Deploys instantly via Vercel

---

## Live Demo 

[Try it now on Vercel](https://recipe-finder-app-sarakhan7s-projects.vercel.app)

## Tech Stack 

- HTML5
- CSS3
- JavaScript (Vanilla)
- [TheMealDB API](https://www.themealdb.com/api.php)  
- Deployed with [Vercel](https://vercel.com)

---

## Run Locally 

Clone the project and run it locally:

```bash
git clone https://github.com/sarakhan7/RecipeFinderApp.git
cd RecipeFinderApp
```

Then just open `index.html` in your browser — or use Live Server if you have it installed in VS Code.
